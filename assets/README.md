# Character art and optional reactions

This source archive includes the project's original MIT SVG characters in the existing theme, mood and dragging layout. Custom artwork in a local data directory keeps priority.

Unicode reactions work immediately. Historical image reactions appear as 🙂.

Fonts and dependencies retain their own [third-party notices](../docs/third-party-notices.md). Existing fan-art PNGs, character atlases and screenshots containing them stay with the original installation; this candidate uses original SVGs.

See the [installer AI guide](../docs/local-emotes.md) for optional local reactions.
