# Character art and optional reactions

This source archive ships original PNG avatars and 16 mood pictures for the three characters (owner, Claude, GPT) under the project license, ready to use after install; the simple SVG drawings remain as a fallback. Custom artwork in a local data directory keeps priority.

Unicode reactions work immediately. Historical image reactions appear as 🙂.

Fonts and dependencies retain their own [third-party notices](../docs/third-party-notices.md). Characters from other works and third-party reactions are not included in the source archive.

See the [installer AI guide](../docs/local-emotes.md) for optional local reactions.
