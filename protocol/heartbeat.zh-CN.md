# 醒来流程

[English](heartbeat.md) · [架构](../docs/ARCHITECTURE.md) · [巡检部署](../docs/night-watch.md)

守夜人用普通脚本观察已配置的任务、同步进度并记录事件。先执行 `python scripts/agent.py --as GPT wake`，再用 `status` 读取完整工作清单。

1. 读取收信变化、精确事件编号和提问；格式异常的记录保留给具体修复。
2. 读取相关任务、当前指令和最近交流，沿原会话、冻结配置和文件归属执行。
3. 完成事件对应的操作后，用 `events --ack 精确编号 --result 结果` 登记。
4. 接着检查实验可用资源、主线指令、开着的任务和退回项；另一项等待决定时继续独立授权工作。
5. 只剩实际依赖后，用带 `--mood` 的 `patrol` 写正在做什么、下一件事和等待对象。

参考部署的会话路由与 GPU 观察由适配器连接。仓库内的 `status` 始终提供任务和流程事项，`wake` 专注收信变化。

## 通知

实质完成、具体故障和用户亲手操作事项向用户报告。健康运行、常规进度和稳定等待写入本地记录，保持安静。

## 部署与节奏

[巡检部署](../docs/night-watch.md)包含 Windows 任务注册、cron、试运行和手动命令。任务巡检、模型会话叫醒、看板启动和卫士保活各自保留配置入口。诊断记录放在项目本地运行文件。
