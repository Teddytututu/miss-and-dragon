# 日常流程说明

以下小功能原先写在 README 首页，现集中放在这里。

每条发起人消息由助手逐条决定答法：文字回复，或用 `react --enough` 明确选择表情就够；普通表情保留待办。

新建任务时会提示看板和归档中的相似名字，方便主线先核对旧任务的范围。

Claude 的可选消息时间提示与 Codex 醒来先看钟，见[安装说明](install-with-agent.zh-CN.md#本机时间提示)。

流程检查按连续达标次数收口：示例核对每个执行角色都有能开工的活，连续十次达标后解决，失败归零。详见[连续检查](process-checks.zh-CN.md)。

[答问指引](../protocol/answering.zh-CN.md)帮助助手先认清进展、概念、关系、来源、原因、方法、价值、安排与交付这九类问题，再给直接回答。
