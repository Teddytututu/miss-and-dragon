# 中文与英文

在侧栏选择 **简体中文** 或 **English**，即可切换导航、操作按钮、自动状态标签、私聊和对话框的语言。浏览器会保存选择，蓝色和粉色主题共用同一语言设置。

中文入口为 `http://127.0.0.1:8780/?lang=zh-CN`，英文入口为 `http://127.0.0.1:8780/?lang=en`。当次访问优先采用网址参数，侧栏选择会保存新的浏览器偏好。

项目名、消息、草稿、研究内容、任务标题和文件名保留原文。语言切换保留项目记录、当前草稿和已打开面板，项目内容可以使用中文或英文。

使用说明提供[中文版](../README.zh-CN.md)与[英文版](../README.md)，本机帮助页也提供[中文](http://127.0.0.1:8780/help.html)与[英文](http://127.0.0.1:8780/help.en.html)。
