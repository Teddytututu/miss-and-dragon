# Everyday workflow notes

Small workflow behaviours that used to sit on the README front page.

Each owner message stays pending until an assistant replies or explicitly chooses `react --enough`; ordinary reactions remain acknowledgements.

New tasks include an advisory list of similar titles from the live board and archive, so the lead can compare scopes before repeating work.

Optional local-clock context for Claude prompts and clock-first Codex wakes are described in the [installation guide](install-with-agent.md#local-clock-context).

Process checks retain consecutive observations: the default example checks that each active execution role has actionable work. Ten due successes close it; a failed observation resets the count. See [process checks](process-checks.md).

The [answering guide](../protocol/answering.md) helps each assistant identify whether a message asks about progress, meaning, relationships, origin, cause, method, value, next action or readiness before replying.
