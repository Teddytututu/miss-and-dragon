# English and Simplified Chinese

Choose **English** or **简体中文** in the sidebar. Your choice stays in this browser and applies to navigation, controls, generated status labels, private chats and dialogs. Blue and pink themes use the same language setting.

Open `http://127.0.0.1:8780/?lang=en` for English or `http://127.0.0.1:8780/?lang=zh-CN` for Simplified Chinese. A URL language takes precedence on that visit. Change the selector to save a different preference.

Project names, messages, drafts, research notes, task titles and file names keep their original wording. Switching the interface language preserves the project records, current drafts and open panels. Write project content in either language.

Start with the [English README](../README.md) or [Chinese README](../README.zh-CN.md). The local help page has [English](http://127.0.0.1:8780/help.en.html) and [Chinese](http://127.0.0.1:8780/help.html) versions.
