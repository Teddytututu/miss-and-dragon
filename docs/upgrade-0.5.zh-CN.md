# 从 0.4.3 升级

保留旧安装目录和数据目录作为回退副本。把新源码 ZIP 解压到另一目录，创建环境并安装 `requirements.txt`，先用 `python -m board start --data-dir <数据副本> --port 18780` 试用。

任务卡、讨论账本、报告和本地自定义图片继续沿原文件。旧报告地址继续使用原阅读目录。已读记录保留浏览器的 `result-tree-read-v1` 键：唯一旧标题记录继续识别，新阅读按节点 ID 或报告路径保存。报告改名保留已读；摘要或主报告引用变化时重新提醒。同名旧记录由每份报告的一次明确阅读分别建立身份。

首页 GET 读取会把昨天完成的事项投影为完成，磁盘日程保持原字节。明确的排程与待办操作继续执行原跨日整理。

资源排期和手动研究包均为可选功能。新增 `attachments/resource-plan.json` 后启用按整票计算的实测计划，统一命令 `scripts/agent.py resource-plan` 和页面调用同一算法。手动研究包存于 `attachments/manual-packets/包名`，侧栏展示各版回答与采用意见。既有工具和页面各区继续使用。

发行归档采用 MIT 原 SVG 人物图。本地数据目录里的自定义图片保持优先。本地同人 PNG 和相关截图随原安装保留；迁入图片时沿各自已取得的使用授权。

## 上个正式版之后的改动

0.4.3 之后的公开 main 已包含网页阅读报告、逐条选择文字或表情回复、任务与实验辅助、语音偏好和自选安装守夜人。本候选新增整票实测排期、多版本手动回件、稳定结果阅读身份、只读首页快照和完整本地研究示例。各安装保留自己的可选服务选择。

在数据副本与浏览器行为确认后选择本地切换时刻，旧代码与旧数据配套保留。候选审核材料列出对应 ZIP 与逐项选择的源码文件。

历史图片表情缺少本机图片时显示为 🙂，原回应记录与本地图片留在项目数据中。[本机表情安装方法](local-emotes.md)。
