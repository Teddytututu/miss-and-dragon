# Writing reports

Use the [report kit](../templates/report-kit/README.md) to make a portable offline HTML report. Start with the research answer, show the comparison and its baseline, then give exact values and next steps. The kit includes figures, tables, image embedding and a form checker.

Read the [format guide](../templates/report-kit/FORMAT.md) and replace the fictional example with your project data. Keep operational records in a separate file.
