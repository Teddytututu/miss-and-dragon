# 每日开源同步

用户在项目设置启用`"open_source_sync": {"enabled": true}`后，使用固定副本和sync/YYYY-MM-DD分支维护。

1. 对照本机改进与公开版，挑适合其他项目的部分。身份、账号、私聊和专属部署留在本机。常规改进先观察一天，用户点名的批次按指定范围执行。
2. 按公开版命名与结构逐项移植，行为改动配测试，每项一个提交，作者使用用户配置的noreply身份。
3. 运行仓库检查并对完整源文件清单做隐私扫描，角色图片与版本选择交用户。
4. 写attachments/open-source-sync/YYYY-MM-DD.md，首行使用“审核：待 Claude”“审核：退回：原因”“审核：通过”或“审核：不需要”。随后写改进、来源、公开位置、提交、说明表，以及省略项、分支、差异、检查和隐私扫描结果。
5. 负责人审阅并记录决定，退回项交GPT修改；22:00后缺当天记录会提醒GPT。发布操作按用户已有授权执行，准备阶段交可审阅分支。

使用[审核模板](../templates/open-source-review.md)。
