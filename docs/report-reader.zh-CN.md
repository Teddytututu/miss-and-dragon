# 在浏览器阅读报告

在 `overview.json` 的 `links` 中填写项目相对路径，HTML、Markdown 和 PDF 文件卡会打开只读阅读页。Markdown 的标题、列表、表格、引用和代码块排成网页，原文件保持原样。`/files/<path>` 继续下载原文件。

阅读页沿 HTML、Markdown 和 CSS 中明确写出的引用读取项目内已有文件。附件地址绑定完整路径，同名的两份文件各自对应原件。链接到另一份已挂报告时使用该报告自己的范围。刷新报告后，引用随原文件更新。

读取前继续执行现有的本地直连检查。阅读入口支持 GET 和 HEAD；范围限定为项目内文件，并排除符号链接、讨论附件与私聊附件。报告脚本与联网请求关闭。本功能沿用本地单用户部署；对外部署采用专门审阅的认证和部署方案。

示例：

```json
{"links": [{"title": "缓存对照", "path": "reports/cache.html"}]}
```

将表格或图片放进项目，并在报告中引用相对路径。新结果页沿用报告工具，运行日志放在配套记录中。
