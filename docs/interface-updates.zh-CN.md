# 界面使用说明

## Discussion history / 讨论室历史

讨论室先显示最近18条，可逐次加载更早消息。首次自动定位未读最多展开120条，手动查看原消息按目标位置加载附近内容。回到底部后更新消息会恢复精简视图。

## Private image cache / 图片私有缓存

头像与表情图片在浏览器私有缓存中保留一分钟，刷新讨论室时复用图片。缓存过期后按图片内容核对版本，替换后的图片自动更新。SVG继续采用独立沙箱策略，消息与文档沿用各自响应策略。

## Message actions / 消息操作

消息下方保留直接回复入口。更多菜单只显示服务器授权的撤回或管理员删除操作，支持键盘选择与手机长按。

## Unread entry / 入口未读提示

讨论室收起时，有他人新消息才显示入口红点。带时区的时间统一换算成实际时刻比较，撤回消息与自己的消息按已读处理。

## Phone discussion / 手机讨论室

手机打开讨论室即铺满可见屏幕，输入区跟随键盘。拖动输入框角标或用方向键调整高度，下次打开沿用设置。平板保留抽屉高度档位，长文件名在输入区内换行。

## Sticky-note replies / 便利贴回一句

鼠标移到便利贴上显示“回一句”，键盘聚焦后回车、手机长按也可打开。输入区有40字计数和发送、取消，留言同时送进讨论室给指派助手，重试沿用原消息。

## Free paper wall / 自由贴墙

便利贴按文字长度定宽，在整面墙寻找空位，左右错落、角度交替，相邻纸张配色错开。刷新保持位置，改变窗口宽度时重新排布，粉蓝主题共用布局。
