# 顺引用关系查论文

先选5至12篇近邻种子，包括直接前身、理论来源和已知对手，交负责人核对。大综述和高被引基础论文容易带来大量背景候选。

1. 同时抓种子的参考文献和引用它的新论文。运行`python scripts/citation_chain.py seeds.txt output --hop2 2`，按paperId去重、记录连接几个种子，并从多种子近邻继续向外抓引用。种子文件每行一个arXiv号，可用#写备注。
2. 用用户已有的Scopus或Web of Science权限、合法开放全文和出版社入口补漏，查询与访问结果写在独立记录里，账号操作按已有授权处理。
3. 关键词只做补充，使用项目机制的多种叫法，结果合入同一候选表。
4. 每篇读摘要并写等级和理由：A直接近邻，B可用方法、测量、理论、数据或基线，C背景，D无关；缺摘要时读第一页或引言。
5. A级读全文，记录测了什么、与项目差在哪，以及引用、比较或修改主张的处理方式。
6. 用负责人给出的已知答案检查覆盖，从新增A级继续查；负责人抽看被筛掉的候选，并对照原文检查最接近的工作。

交付先写新颖性判断，再给直接近邻表、可用方向和完整分级CSV。访问日志与阅读状态单独保存。

每日运行时换一个带日期的输出目录：`python scripts/citation_chain.py seeds.txt output/YYYY-MM-DD --since YYYY-MM-DD --exclude seen.csv`。每日模式只抓新引用，按日期筛选并跳过seen.csv中paperId列已有的论文；缺日期的记录留在该筛选范围之外。读摘要分级后选少量有用论文，记录已推送编号。缓存供中断续跑，新的日期目录会刷新检索；限速时按服务规则稍后继续。
